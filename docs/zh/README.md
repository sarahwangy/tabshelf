# Tab Saver

**Language:** [English](../../README.md) | 简体中文

一个 Chrome 浏览器插件，可以把打开的标签页的网址和标题保存到本地的一个 JSON
文件中，并提供一个管理页面用来浏览、整理和删除已保存的链接。

## 环境要求

- **Google Chrome 116 及以上版本**（或其他支持"文件系统访问 API"的
  Chromium 内核浏览器）。文件系统访问 API 是插件读写本地磁盘文件所依赖的能力
  ——Firefox 和 Safari 目前不支持。
- **Manifest V3** 插件——不需要额外的运行环境或构建步骤，直接作为"已解压的
  扩展程序"加载即可。

## 权限说明

在 `manifest.json` 中声明的权限：

- **`tabs`**——用于读取你打开的标签页的网址和标题（以便保存），以及在你开启
  "保存后自动关闭标签页"选项时关闭标签页。Tab Saver 不会读取网页内容，只读取
  标签页的元数据。

不需要 `downloads` 权限或任何网站访问权限。保存链接的 JSON 文件的读写权限，是
通过浏览器原生的文件选择器（文件系统访问 API）单独逐个文件授权的，与
`manifest.json` 中声明的权限无关。

## 加载插件

1. 打开 `chrome://extensions`。
2. 打开右上角的"开发者模式"开关。
3. 点击"加载已解压的扩展程序"，选择本项目所在的文件夹。

## 使用方法

> 想看图文并茂的详细教程，请参阅[使用指南](./user-guide.md)。

### 首次设置

1. 点击 Tab Saver 工具栏图标。
2. 点击"保存全部标签页"或"保存当前标签页"——由于还没有连接任何文件，这时会
   直接弹出文件选择框，用来创建或选择保存链接的 JSON 文件，选完后立即完成保
   存。接下来会再提示一次，用于可选地选择一个备份文件——它的内容会在每次保存/
   删除时与主文件保持同步；取消这次弹窗即可跳过备份文件。
   （你也可以提前在管理页面连接文件：点击"查看已保存的链接"，再点击"连接一个
   文件"。）

### 保存标签页

- 在弹出面板中点击**"保存所有标签页"**，保存当前所有窗口中打开的标签页；或者
  点击**"保存当前标签页"**，只保存当前活动的这一个标签页。已经保存过的网址会
  被自动跳过。只会保存 `http(s)` 页面——内部的 `chrome://` 页面会被忽略。
- 打开设置面板（弹出框中的 ⚙ 图标），开启**"保存后自动关闭标签页"**，这样每次
  保存后对应的标签页会被立即关闭。

### 管理已保存的链接

打开管理页面（弹出框中的"查看已保存的链接"，同时会显示当前保存的链接总数），
可以：

- 按**域名分组浏览**链接，支持**列表**和**卡片**两种视图（在页面头部切换，你
  的选择会被记住）。列表视图现在也会给每条链接展示一个小封面缩略图（YouTube
  视频显示真实缩略图，其他链接显示彩色图标块），和卡片视图风格一致。
- 按标题或网址**搜索**——无论当前是哪种视图都会生效。
- **排序**：可按"最近添加""最早添加""标题 A→Z""标题 Z→A"排序（搜索框旁边的
  下拉菜单，你的选择会被记住）。"最近 7 天"和"最少查看"视图有各自固定的排序，
  不显示这个下拉菜单。
- **按站点分组**（排序旁边的复选框，默认勾选）——取消勾选后会关闭域名分组，
  所有保存的链接会按你选的排序方式打平成一个列表统一排序。是否分组的选择也
  会被记住；点击站点索引里的某个站点时会自动重新勾选分组，因为跳转到分组需
  要先有分组存在。
- **站点索引**（左侧边栏，收藏上方）——列出你保存过链接的所有不同域名（比如
  "github.com""youtube.com"），每个站点显示图标和链接数量。点击某个站点可以
  直接跳转到页面下方对应的域名分组。
- 点击 ★ 按钮**收藏**一条链接，将它固定在左侧侧边栏中，收藏的链接还可以**拖动
  排序**。收藏的链接也会自动排到所在域名分组的最前面，含有收藏链接的分组本身
  也会排在其他分组前面。
- **最近 7 天**（左侧边栏，收藏下方）——列出最近有保存过标签页的日期（没有标
  签页的那天会被跳过，并往更早的日期找，凑够最多 7 个日期），离今天近的排在
  上面。点击某个日期，可以把主列表筛选为只显示那一天保存的标签页；再次点击
  同一个日期可以取消筛选。
- **最少查看**视图——第三种视图模式，展示你打开次数最少的 5 条保存链接（打开
  次数相同时，优先展示保存时间最早的），方便你快速找回保存后就忘记看的内容。
  在任意视图中点开一条链接都会被记录一次打开。
- 点击"删除"按钮**移除**一条链接。当一个域名分组的最后一条链接被删除时，这个
  分组会自动消失。
- **多选批量删除**——把鼠标悬停在一条链接上（列表或卡片视图都可以），左上角
  会出现一个复选框；勾选几条之后（勾选过的复选框会一直显示，不需要一直悬停
  着），列表上方会出现一个提示条，显示已选中几条，并提供**"Delete
  selected"**（会弹窗确认，删除后无法撤销）和**"Cancel"**（取消选中）两个
  按钮。
- 点击页面头部的**"更换文件"**按钮，可以切换管理页面读写的目标文件。

Tab Saver 是所连接的 JSON 文件唯一预期的写入者。如果连接的文件无法解析，或者
虽然是合法 JSON 但不符合预期的 `{ "links": [...] }` 结构（例如指向了某个无关的
`.json` 文件），插件会检测到这一点并拒绝写入——它绝不会向其中合并标签页数据，
也不会覆盖它。
